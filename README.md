## 安装

在**云崽根目录**执行。三个源任选一个（内容完全一样，推荐国内的 gitcode 或 gitee）：

**gitcode（国内直连最快）**
```bash
git clone --depth=1 https://gitcode.com/ccxhan/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
```

**gitee（国内）**
```bash
git clone --depth=1 https://gitee.com/longhengmu/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
```

**GitHub**
```bash
git clone --depth=1 https://github.com/cchanlan/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
```

装依赖：

```bash
pnpm install
```

重启 Bot 即可。先 `#绑定营地` 才能查自己的数据。

## 绑定账号

```
#绑定营地 1580886057      营地 ID（营地 App「我的」页可见）
#切换营地 2               多号时切换
#删除营地 2
#营地wx登录               微信扫码登录，拿到更完整的数据权限
#营地QQ登录               QQ 扫码登录（微信区/QQ 区玩家都能用，看你自己绑的营地号）
#营地wx全局登录            微信扫码登录，登录后可用 #营地观战
#营地QQ全局登录            QQ 扫码登录，登录后可用 #营地观战
```

大部分查询指令都支持 `@某人`（对方也得绑过）和直接写营地 ID，比如 `#查询战绩 @张三`、`#排位表现 1580886057`。

### 登录态会过期吗

营地的登录态是「**用则续命、闲置才死**」——天天在用的号不会过期，搁久了才会失效。
所以插件每天会自动给每个号**保活**一次（微信、QQ 都适用），一般不用管：

- 想手动催一次：`#营地续期`（请主人发）
- **QQ 号**万一还是失效了，插件会用存着的登录凭证**自动重登救回**，不用重新扫码
- **微信号**没有可重放的凭证，失效了只能重新扫码（`#营地wx全局登录`）

保活时间在配置里（`campRenewCron`，默认每天 5:13；留空 = 只手动）。

## 营地观战

> `#营地观战` 可以简写成 `#观战`，下面所有用法都能换着发（如 `#观战 在播`、`#观战 停`）。

| 指令 | 说明 |
| --- | --- |
| `#营地观战` | 看**自己**营地好友里谁正在对局（含段位、开局多久，图上有编号） |
| `#营地观战 列表` | 同上（别名，和直接发 `#营地观战` 一样：看谁在打） |
| `#营地观战 <编号>` | 开一路直播，群里发个链接，群友点开就能看，手机电脑都行 |
| `#营地观战 在播` | 看现在有哪几路直播在跑（别名：`正在播`、`直播间`、`room`、`rooms`） |
| `#营地观战 停` | 停掉**自己开的**直播间，别人在看的不受影响（别名：`停止`、`关`、`关闭`、`stop`） |
| `#营地观战 停 <编号>` | 停指定的一路（编号看 `#营地观战 在播`，不是名单图上的编号；`停`/`停止`/`关`/`关闭` 都行） |
| `#营地观战 停 全部` | 停掉全部直播间（别人开的也会停；`全停`、`停全部`、`关闭全部`、`全关`、`全部关` 也认） |
| `#营地开播` | 开「本群最近提示的那一场」——订阅上下线提醒的人开局满几分钟后，群里会收到一条开播提示，发这个就开那一路 |
| `#营地观战部署` | 一键装好观战服务（pm2 托管、开机自启）；已经在跑就是重启。请主人发 |
| `#营地观战服务` | 看观战服务跑没跑、ffmpeg 就绪没、对外地址配了没。请主人发 |

看的是**发起人自己的营地好友**，所以要先 `#营地QQ全局登录` 或 `#营地wx全局登录` 扫码
（这两条所有人都能发，登录态记在扫码人名下）。没登录过就发观战，会提示去扫码。
`#营地观战 停` 不要求登录 —— 但**只停自己开的**那几路，不会影响别人正在看的；
要全停得明确发 `#营地观战 停 全部`。

一个对局一路，每路一个独立网址和独立聊天室，互不干扰。**一路要占一个账号**，
所以能同时开几路取决于有几个登录过的号加过营地好友（名单图上会标出哪几行现在开得了）。

**开播提示**：订阅了上下线提醒的人一上线，后台会盯着他进对局；进对局满几分钟
（默认 3 分钟，`watchHintAfterMin` 可改）且确认这一局能看（是全局账号好友 + 排位/巅峰赛 +
没关战绩）时，往他订阅的群里发一条提示，群里**任何人**发 `#营地开播` 就能开这一路
（不 @ 订阅者，也不需要订阅者本人来发）。不是全局账号好友的号不会收到提示 ——
取流必须过「是不是好友」这关，不是好友的话提示了也开不了。

观战要**另跑一个后端进程**（负责取直播流和录像），机器上还得有 ffmpeg。一条指令装好：

```
#营地观战接入 <地址> <令牌>
```

**地址和令牌进群 `972915804` 找主人要。** 这一条一步到位：写入配置 → 下载服务端代码 → 用 pm2 托管起来。
装完发 `#营地观战服务` 能看状态（进程、ffmpeg 就绪没、对外地址配了没）。

> 服务端代码从**主人的分发服务**下载（不再从 git 仓库拉），所以它不会出现在任何公开平台上。
> 换地址或令牌就重发一次接入指令；只是更新代码发 `#营地观战部署` 就行。

服务默认监听 `8899`。装完记得在配置里把**直播间对外地址**填成外网能访问的（域名或公网 IP），
不然发出去的链接只有本机能开、群友点了是白屏。别忘了防火墙 / 安全组放行这个端口。

播放页上有个「开始录像」按钮，默认不录；点了就录，再点一下停止并保存成 mp4，
忘点停止的话对局结束会自动收尾。

### 直播间的聊天室和弹幕

群友点开链接就能一起聊，发的话会同时**飘成弹幕**（右下角「弹幕」可以关，记在本机）。
竖屏是「上面看画面、下面聊天」，横屏画面占满、点「聊天」滑出抽屉。
进门自动分配一个临时昵称，点一下就能改。

聊天记录只在内存里留最近 100 条，**换直播间或重启服务就清空**，不落盘。
不想要这个功能的话，启动服务时加 `GOK_CHAT=0` 就能关掉。

## 营地消息

营地好友发来的消息会**转到你的 QQ 私信**，你可以直接回。

推送长这样：

```
[对方游戏头像]
📩 我就只会补兵
加油啊小哥哥
（微信安卓 荣耀王者）

回复：引用这条消息，或发 #营地回复 1580886057 <内容>
```

| 指令 | 说明 |
|---|---|
| **引用那条推送回一句** | 直接回复对方 —— 引用机器人发的那条营地消息推送，发你想说的话 |
| `#营地回复 <营地号> <内容>` | 不用引用也行，指定用哪个号回 |
| `#营地好友` | 看**当前营地号**的好友里谁在游戏里，图上有编号（**只认私聊**） |
| `#营地私聊 <编号> <内容>` | 按编号给 TA 发消息（**只认私聊**） |
| `#营地消息` | 看服务状态、哪些号在线、还有多少条待处理 |
| `#营地消息部署` | 一键装好营地消息服务（pm2 托管）。请主人发 |
| `#营地消息服务` | 看营地消息服务跑没跑、各号连上没有。请主人发 |
| `#营地消息同步` | 按锅巴里的开关重新连账号（别名：`#营地消息重连`）。请主人发 |

**主动找人聊**：`#营地好友` 只列**在游戏里**的好友（客户端开着王者），
图上每个带编号，发 `#营地私聊 <编号> <内容>` 就发过去了。
用的是 `#切换营地` 选中的那个号 —— 换号就换一批好友。
编号 10 分钟内有效，超过要重新看一次列表。

**推给谁**：每个营地号的收发**只推给它的归属人** —— 归属人是扫码登录时记下的，
想换人去锅巴的「账号列表」改「归属 QQ」。**没有归属人的号一律不推**。

**哪个号收消息**：在锅巴的侧边栏「营地消息」页面逐个开关，或者在插件配置里
「哪些营地号收消息」那张表里勾。两边是同一份开关，改完几秒内生效，不用重启。

**过滤**：只推真人好友消息 —— 对局直播流推送、公众号消息一律不推。

### 服务端怎么跑

营地消息要**另跑一个后端进程**（每个营地号挂一条长连接收消息），插件通过本地
HTTP 指挥它。一条指令装好：

```
#营地消息接入 <地址> <令牌>
```

**地址和令牌进群 `972915804` 找主人要**（和观战共用同一个地址和令牌）。这一条一步到位：
写入配置 → 下载服务端代码 → 用 pm2 托管起来。服务默认监听 `8900`（配置里 `campImApiUrl` 可改）。

> 服务端代码从**主人的分发服务**下载（不再从 git 仓库拉）。只更新代码发 `#营地消息部署` 就行。

## 营地ID 共享（可选的跨机器人功能）

你在 A 群的机器人上绑过营地ID，被拉到 B 群（另一个 bot 主人搭的实例）时，
不用重新绑定就能直接查战绩。

**默认不共享**，要自己发指令开：

```
#开启营地ID共享        把你的营地ID传上去，之后换机器人免重绑（#开启营地共享 / #打开营地共享 也行）
#关闭营地ID共享        取消共享（#取消营地共享），之前传上去的也会删掉
#营地ID共享状态        看看自己开没开、共享了哪些号
#同步营地ID共享        把你的绑定传到共享库，别的机器人立刻能查到（只推这一次）
```

上传的是「QQ 号的加盐哈希 → 营地ID」。**不上传登录态、不上传战绩，一个字的凭证都不上传。**

几条要知道的边界：

- **共享库由主人统一提供**，不再支持自己搭（服务端代码不再公开）。
  **地址和令牌进群 `972915804` 找主人要**，拿到之后三步接上：
  `#营地共享库地址 <地址>`、`#营地共享库令牌 <令牌>`、`#接入营地共享库`。
- **本机要有可用的全局账号**（`#营地wx全局登录` 或 `#营地QQ全局登录`），共享过来的营地ID 才查得动。
- **共享数据会落到本机**：你在别的机器人上绑过的号，本机查过一次之后就会记下来，
  之后 `#查询战绩`、`#排位表现`、`#排位排名`、`#皮肤墙` 这些**全都认**。
  （落下来的那份带来源标记，你 `#关闭营地ID共享` 时会自动清掉。）
- **但它是按需落地的**：没人查过的号不会主动同步过来。所以跨机器的排行榜通常只统计
  「本机查询过的人」，不是全部 —— 想让某个号出现在本机，用它发一次查询就行。
- **序号只认本机**：`#查询2战绩` 里的「2」指的是本机绑定的第 2 个号。
- **撤销几乎立刻生效**：别的机器人下次查询（几秒内）就看不到你的数据了。
- 库里只存 QQ 的**加盐哈希**、不存明文；但接入方拿着自己的令牌、用群成员里的 QQ
  逐个查是能刷出池子的。QQ 号本身不是秘密，介意的话就别开这个功能。

主人侧指令（仅私聊）：

```
#营地共享库              查看接入状态、地址、令牌、缓存条数
#营地共享库发令牌 <备注>   给别人的机器人签一个令牌；@一下群友就直接私聊发给 TA
#营地共享库接入方          看谁在用你的共享库（#营地共享接入方 也行）
#营地共享库吊销 <序号>     踢掉某个接入方
#营地共享库同步           把你自己和本机开过共享的人一起对上库（自动同步没生效时手动推）
#营地共享库查 <QQ>         问库里有这个 QQ 的记录没，排查「对方说我没绑定」用
#营地共享库地址 <地址>     设置共享库地址（要带 http:// 或 https://）
#营地共享库令牌 <令牌>     设置共享库令牌
#营地共享库管理密钥 <密钥>  远程管理：库跑在别的机器/Docker 上时，填服务端的
                           GOK_ADMIN_SECRET，发令牌/接入方/吊销照样能用（只收私聊）
#接入营地共享库 / #关闭营地共享库
#营地共享库提醒           重新私聊发一次接入提醒
```

> 共享库**不再支持自行部署**（`#营地共享库部署` / `#状态` / `#卸载` 三条已移除）——
> 服务端代码不公开了，想要的人进群 `972915804` 找主人要地址和令牌。

主人给别人的机器人签令牌：发 `#营地共享库发令牌 某某的机器人`，
把回复里那三行整段转给对方就行。

**库不在本机也能管**：共享库跑在主人自己的服务器上，机器人这边照常三步接入，
再私聊发一次 `#营地共享库管理密钥 <服务端 .env 里的 GOK_ADMIN_SECRET>`，
之后发令牌、看接入方、吊销，都是直接管你接入的那个远程库。

在群里想省掉转发这一步，就直接 `#营地共享库发令牌 @某人`：机器人会把令牌私聊发给 TA
（备注可以省，默认用 TA 的昵称）。对方没开临时会话、或者没加机器人好友时发不出去，
这种情况令牌会退回私聊给主人，群里只说一句「没发出去」—— 令牌永远不出现在群里。

首次安装和每次更新后，插件会私聊主人问一次要不要接入（已接入或已经说过不要的不会再问）。

## 服务端分发（观战 / 营地消息的代码从哪来）

观战和营地消息都要另跑一个后端进程。这些服务端的**代码不再放在公开仓库里**，
改由**主人服务器上的「分发服务」**按需下发：

```
#营地观战接入 <地址> <令牌>     一步接入并部署观战服务
#营地消息接入 <地址> <令牌>     一步接入并部署营地消息服务
```

**地址和令牌进群 `972915804` 找主人要**（两个服务共用同一个地址和令牌）。
只是更新代码就发 `#营地观战部署` / `#营地消息部署`，不用重新接入。

> 主人侧的运维指令（部署分发服务 / 签发令牌 / 看接入方 / 吊销）**不在这个仓库里** ——
> 它们放在插件目录的 `local/` 下，只跟着主人自己那台机器人走，别人的机器人不会有。
> 换机器时从私库 `cchanlan/gok-server` 取一份放进 `local/` 即可。
>
> **一个令牌通吃三套**：分发服务签发令牌时如果配了共享库，它会代共享库签一个，
> 于是同一个令牌既能部署观战 / 消息，也能接入共享库。
>
> 分发服务本身零依赖（只用 Node 内置模块），默认端口 `6868`。
> **强烈建议反代成 HTTPS** —— 明文 HTTP 下令牌和代码都会明文过网。

## 拉黑某人（主人）

```
#王者拉黑@某人        也可以写 QQ 号：#王者拉黑 10001
#王者取消拉黑@某人
#王者黑名单           看当前名单，锅巴面板里也能直接改
```

名单里的人发任何王者指令都不会有回应，之前订阅的战绩推送、上下线提醒、日周月报也不再推，
群报和排行榜里也不统计他。订阅和绑定的数据一个都不删，移出名单就恢复原样，主人不受影响。

默认还会跟随机器人自身的黑名单（`config/config/other.yaml` 的 `blackUser` / `blackQQ`）：
那份名单只挡用户主动发的指令，挡不住插件按时间主动发的推送，所以「人早就拉黑了、战绩推送还在推」
这种情况靠它一并停掉。不想跟随可以在 `#王者设置` 里关掉。
